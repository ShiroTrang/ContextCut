# P2 — Phụ đề, nhìn, xuất: kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agent nghe được lời thoại (transcript theo từ, có người nói, timing chuẩn) và đặt phụ đề đầy đủ + câu đắt lên timeline; xem được hình (nguồn, timeline đã dựng, khung đang xem); xuất được file YouTube 1080p60 đã kiểm bằng ffprobe; có `zoom` thay facecam.

**Architecture:** Phân tích nặng chạy trong **tiến trình worker riêng** của `contextcut-ai` (`python -m contextcut_ai.analysis.worker <job.json>`), tách khỏi MCP server: job sống qua việc client đóng/mở lại server, khoá GPU toàn máy (một job GPU một lúc), VRAM trả hết khi tiến trình thoát. Kết quả cache theo hash file trong `<project>.contextcut/`. Phần "thông minh" (ghép từ thành dòng phụ đề, ánh xạ thời gian nguồn → timeline, style theo người nói) ở Python; app chỉ thêm op phụ đề tổng quát vào registry P1c (một đợt = một bước undo như cũ).

**Tech Stack:** như P1; thêm extra uv `analysis`: `faster-whisper` (CTranslate2 4.x, CUDA 12) + `nvidia-cublas-cu12` + `nvidia-cudnn-cu12` (9.x) từ PyPI, `nvidia-ml-py` (đo VRAM); ffmpeg/ffprobe; model trong cache HuggingFace có sẵn trên máy Nhan (`Systran/faster-whisper-large-v3` 3,1 GB, `vinai/PhoWhisper-large` 6,2 GB).

**Spec:** `docs/specs/2026-10-21-contextcut-design.md` §4, §8.1, §8.3, §8.8, §9, §12 (hàng P2), §14; `docs/specs/kien-truc-v3.md` mục "Pipeline phân tích → Audio", "AI nhìn được gì", "Preview và xuất bằng MLT", "Kiểm thử", "Ngân sách VRAM 6 GB". Giao thức: `docs/protocol.md`.

## Global Constraints

- Mọi ràng buộc của `docs/plans/P1.md` (fork mỏng, `.kdenlive` không đổi định dạng, frame nguyên + nửa mở, một đợt = một bước undo `AI: …`, hỏi trước khi push / ghi cấu hình client) vẫn giữ.
- Thư viện phân tích nằm trong extra `analysis` (`uv sync --extra analysis`); MCP server **chạy được khi không có extra**: tool phân tích trả câu hướng dẫn cài thay vì lỗi import.
- Một job GPU nặng một lúc trên cả máy (khoá file `%LOCALAPPDATA%\contextcut\gpu.lock`); VRAM trả hết sau mỗi job (worker thoát). RTX 3060 6 GB: đỉnh VRAM toàn card phải < 6144 MiB.
- Model chỉ từ nguồn chính thức (HuggingFace của tác giả, PyPI, download.pytorch.org). Mặc định **không tải**: thiếu model thì tool báo tên + dung lượng và chỉ tải khi người dùng đồng ý (`allow_download=true`). Báo Nhan dung lượng trước mọi lần tải.
- Không ghi gì cạnh file bản ghi; bản ghi chỉ đọc. Dữ liệu AI ở `<project>.contextcut/` (project chưa lưu → yêu cầu lưu trước).
- Transcript lưu thời gian **giây trên bản ghi gốc** (3 chữ số thập phân); tool trả frame (timeline hoặc nguồn, theo fps project).
- Chạy được không GPU: CPU `int8` (chậm hơn), xuất `libx264`.
- Tiếng Việt trước; `language` là tham số.

**Dữ liệu trong `<project>.contextcut/`:**

```
recordings.json                    {"schema": 1, "recordings": {"<rec_id>": {"path", "file_hash", "size", "track_map": [...], "streams": [...]}}}
speakers.json                      (tuỳ chọn) {"Nhan": {"color": "#FFFFFF"}, "bạn bè": {"color": "#FFD400"}}
analysis/<file_hash>/transcript.json
analysis/<file_hash>/asr/<index>-<model>-<lang>/chunk-<NNNN>.json   (để chạy tiếp)
```

`track_map` là danh sách theo stream audio: `{"index": 2, "obs_track": 2, "title": "Mic", "channels": 1, "role": "mic", "speaker": "Nhan", "transcribe": true}`; `role` ∈ `mix | mic | discord | game | desktop | other`. `index` là chỉ số stream tuyệt đối (ffprobe = MLT, như `list_recordings.audio_streams[].index`).

**Quyết định đo (Task 7):** ứng viên = `large-v3` (int8_float16), `phowhisper-large` (CT2 float16, chuyển tại máy) và `parakeet-ctc-vi` (`nvidia/parakeet-ctc-0.6b-Vietnamese`, NeMo, CTC có timestamp từ; Nhan thêm 22/10 và đồng ý tải ~5,5 GB; extra riêng `parakeet`). Mỗi ứng viên đo thêm **tinh chỉnh ranh giới bằng năng lượng** trên track sạch (Mic/Discord riêng nên ranh giới câu = chỗ có tiếng). Chọn mặc định: WER thấp hơn, miễn trung vị lệch đầu/cuối câu (sau tinh chỉnh) < 100 ms; nếu cả hai không đạt mới xét căn chỉnh CTC wav2vec2 (model mới → hỏi Nhan trước khi tải). Bộ đo tạm khi chưa có bản ghi: 3 bài hát SongMV Nhan đã gõ tay (stem giọng Demucs, 1083 chữ; hát khác nói nên chỉ để xếp hạng, không dùng cho cổng).

### Task 1: Hợp đồng P2a

**Files:** Modify `docs/protocol.md` (§5 kiểu `items`, §8 bảng method, §8.5 op mới, §8.9 `list_subtitles`).

**Interfaces — Produces (cài ở Task 8):**
- Kiểu tham số `items`: mảng object, `min_items`/`max_items` trong `list_operations`.
- Op `add_subtitles{items: [{start_f, end_f, text, speaker?}] (1…5000), layer? (0)}`: thêm từng dòng vào track phụ đề (tạo track nếu chưa có); các dòng không chồng nhau và không chồng phụ đề có sẵn trên layer đó; `speaker` ghi vào trường Name của ASS. `created` = id phụ đề mới.
- Op `clear_subtitles{start_f, end_f, layer?}`: xoá phụ đề **bắt đầu** trong `[start_f, end_f)` (layer bỏ trống = mọi layer).
- `caption` thêm `color?` (`#RRGGBB`), `uppercase?` (bool, mặc định `false`), `label?` (bool, mặc định `true` = thêm "<speaker>: ").
- `cut_range`: phụ đề nằm trọn trong khoảng bị xoá, phụ đề cắt ngang bị thu lại, phụ đề sau khoảng dời lên (hết cảnh báo "phụ đề chưa dời").
- Method `list_subtitles{start_f?, end_f?, limit? (1…1000, 200), cursor?}` → `{revision, items: [{id, layer, start_f, end_f, text, speaker}], next_cursor}` (lấy phụ đề giao khoảng, sắp theo `start_f`, `layer`).

### Task 3: Job nền, khoá GPU, `get_job`/`cancel_job`

**Files:** Create `src/contextcut_ai/jobs.py`, `src/contextcut_ai/analysis/__init__.py`, `src/contextcut_ai/analysis/worker.py`, `tests/test_jobs.py`. Modify `mcp_server.py` (+ `get_job`, `cancel_job`), `tests/test_mcp_server.py`.

**Interfaces — Produces:**
- File job `jobs_dir()/<job_id>.json` (ghi nguyên tử: file tạm + `os.replace`): `{"id", "kind", "params", "status": "queued|running|done|failed|cancelled", "stage", "progress" (0…1), "eta_s", "created_at", "started_at", "finished_at", "pid", "result", "error", "log"}`.
- `jobs.submit(kind: str, params: dict) -> dict` (tạo file `queued`, sinh `sys.executable -m contextcut_ai.analysis.worker <file>` với `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW`, stdout/err vào `<job_id>.log`); `jobs.get(job_id) -> dict` (`running`/`queued` mà pid đã chết → ghi `failed`, `error: "worker dừng bất ngờ"`); `jobs.recent(limit=10)`; `jobs.cancel(job_id)` (đặt `cancel_requested`, worker dừng ở mốc chunk kế; `queued` thì huỷ ngay).
- `jobs.GpuLock` (context manager, `msvcrt.locking` trên file `gpu.lock`, chờ có hạn, cập nhật job `stage: "chờ GPU (job khác đang chạy)"`).
- `worker.main(job_file)`: đọc job → `KINDS[kind](job, report)` → `done` + `result` / `failed` + `error` (traceback vào log); `report(stage, progress)` ghi file job, ném `Cancelled` khi có `cancel_requested`. `KINDS` có `"sleep"` (chỉ để test, giữ GPU lock `seconds` giây) và `"transcribe"` (Task 5).
- MCP `get_job(job_id?: str)` (không id → `recent()`), `cancel_job(job_id)`.
