# P0 — Nền: kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repo `ContextCut` có đủ lịch sử Kdenlive, build bằng một lệnh trong MSYS2 riêng, chạy song song với Kdenlive gốc với cấu hình tách riêng, không nạp plugin Waves.

**Architecture:** Nhánh `main` đặt trên tag `v26.08.2` của Kdenlive (remote `upstream`), remote `origin` là GitHub private. `packaging/build.ps1` (Windows) gọi `packaging/build.sh` trong MSYS2 UCRT64 ở `D:\ContextCut\env\msys64`; script cài phụ thuộc, configure theo flag PKGBUILD của MSYS2, build có ccache, cài vào `stage/`. Đổi tên tối thiểu bằng cách đổi `componentName` của `KAboutData` thành `contextcut` và cho dữ liệu cài vào `bin/data/contextcut`, mọi chỗ sửa file gốc ghi trong `patches.md` và đánh dấu `// ContextCut:` trong code.

**Tech Stack:** C++/Qt 6.11, KF 6.31, MLT 7.40, CMake + Ninja + ccache, MSYS2 UCRT64 (GCC 16.2), bash + PowerShell 5.1.

**Spec:** `docs/specs/2026-10-21-contextcut-design.md` (mục 0, 5, 6, 11, 12) và `docs/specs/kien-truc-v3.md` (mục "Fork Kdenlive", "Cấu trúc repository").

## Global Constraints

- Chỉ dùng MSYS2 ở `D:\ContextCut\env\msys64` (UCRT64). Không đụng `C:\msys64`.
- Đường dẫn đưa cho công cụ Windows (cmake, ninja, melt, gcc) luôn qua `cygpath -m`.
- Từ PowerShell chỉ gọi MSYS2 qua file script (`bash -l script.sh`), không truyền lệnh inline.
- Không chạy `du -sh /` trong MSYS2.
- Flag configure: `-DUSE_DBUS=OFF -DFETCH_OTIO=OFF -DBUILD_TESTING=OFF -DBUILD_QCH=OFF -DKDE_INSTALL_USE_QT_SYS_PATHS=OFF`, Release, ccache, Ninja.
- Định dạng file `.kdenlive` không đổi; project phải mở được bằng Kdenlive gốc.
- Mọi chỗ sửa file gốc của Kdenlive ghi vào `patches.md` (file, lý do) và có chú thích `// ContextCut:` (hoặc `# ContextCut:`) tại chỗ sửa.
- Không dùng Kdenlive/KDE làm tên sản phẩm; About ghi "dựa trên Kdenlive".
- Chỉ tải từ nguồn chính thức (repo.msys2.org qua pacman, invent.kde.org, github.com) vì `D:\ContextCut` không bị Defender quét.
- Commit kết thúc bằng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Hỏi Nhan trước khi push lên `origin`.
