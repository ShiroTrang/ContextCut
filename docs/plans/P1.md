# P1 — Cầu nối: kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AI agent (Claude Code, Codex, Antigravity) đọc và sửa timeline đang mở trong ContextCut qua MCP; mỗi đợt sửa của AI là một bước undo có nhãn, sửa tay chen ngang thì đợt bị từ chối.

**Architecture:** Trong app, `AiBridgeServer` (QWebSocketServer chỉ nghe `127.0.0.1`, token mỗi lần chạy ghi trong `bridge.json`) nhận JSON-RPC 2.0 và chạy từng request trên GUI thread; đọc mô hình timeline Kdenlive (`TimelineItemModel`, `ProjectItemModel`) và, từ P1c, gọi các hàm `request…(…, Fun &undo, Fun &redo)` rồi `pCore->pushUndo` một lần cho cả đợt. Ngoài app, `contextcut-ai` (Python, uv) là MCP server stdio, chuyển tool call thành JSON-RPC qua `bridge_client`. Hợp đồng giữa hai bên: `docs/protocol.md`.

**Tech Stack:** C++/Qt 6.11 (`Qt6::WebSockets`), KF 6.31, MLT 7.40, MSYS2 UCRT64; Python 3.11 + uv, `websockets`, `mcp` SDK (ghim phiên bản chính xác).

**Spec:** `docs/specs/2026-10-21-contextcut-design.md` (§5, §8.8, §9, §10, §11, §12 hàng P1) và `docs/specs/kien-truc-v3.md` (mục "AI chỉnh trực tiếp và nhìn video", "MCP tools", "Timeline và thao tác", "Bảo mật"). Giao thức: `docs/protocol.md`.

## Review Focus

1. **App mở nhưng chưa có project, hoặc project đang nạp** (màn hình chào, thanh tiến độ nạp) → request trả `no_project`/`busy`, app không crash. Kiểm ở Task 4 (bước kiểm thủ công lúc app vừa mở).
2. **`bridge.json` cũ sau khi app crash, hoặc hai ContextCut cùng chạy** → client báo "Mở ContextCut trước" thay vì treo; app chỉ xoá file nếu token trong file là của mình. Kiểm ở Task 3 (`bridge_probe.py check` với file cũ) và Task 6.
3. **Timeline lớn** (bản ghi 2 giờ bị cắt thành hàng trăm clip) → `get_timeline` phân trang, mỗi trang ≤ `limit`, ghép các trang ra đúng tập item, không trùng không sót; cursor của revision cũ → `stale_cursor`. Kiểm ở Task 5 (`check` duyệt với `limit=1`).
4. **Nhiều sequence, đổi sequence hoặc đổi project giữa lúc đọc và lúc sửa** → revision đổi. Kiểm ở Task 4 bằng tay (đổi tab sequence, xem revision).
5. **Trang web mở `ws://127.0.0.1:<port>`** (Cross-Site WebSocket Hijacking) → bị từ chối ở bước bắt tay vì có `Origin`. Kiểm ở Task 3 (`check` gửi `Origin`).
